# Guzo Call Center - desktop builds

Installers for the Guzo Call Center desktop app. Installed apps update
themselves from the latest release here.

- [Releases](https://github.com/serdo-com/callcenter-releases/releases) - one per build: Windows Setup exe, Linux AppImage, rpm and deb
- [RELEASES.md](RELEASES.md) - log of every publish, newest first
- [build-number.json](build-number.json) - the build counter

Everything here is written by the app's publish script. Do not edit by hand.
